# Prompt Motion: makita muna ang animation, bago ang prompt

Kung galing ka sa comment na **MOTION**, nasa tamang lugar ka. 👋
Tigilan na ang panghuhula kung ano ang ita-type kay Claude. Sa **Prompt Motion**, makikita mo muna ang tapos na motion graphics, kasama ang mismong prompt o skill sa likod nito.

**Link:** [prompt-motion.com](https://prompt-motion.com)

> **Na-check noong Nobyembre 2026:** library ito ng motion videos na gawa sa Claude Opus, bawat isa may kasamang prompt o skill na puwedeng kopyahin. **Libre** ang Customize tool nila. Kailangan mo pa rin ng sarili mong Claude account (o Claude Code) para gawin ang video. Laging i-review ang resulta bago i-post.

---

## 1. Pumili ng halimbawa

Sa [prompt-motion.com](https://prompt-motion.com), i-filter ayon sa klase: Product UI, Phone, Charts, Diagrams, **Kinetic type**, Shapes at iba pa. Pumili ng animation na gusto mo ang dating.

## 2. Buksan ang prompt at palitan ang detalye

Buksan ang prompt ng napili mo at palitan ang mga detalye (salita, kulay, haba) para sa sarili mong project.

## 3. O gamitin ang libreng Customize tool

I-click ang **Customize a prompt**, ilagay ang:
- **Topic:** tungkol saan ang video mo
- **Brand colors:** kulay ng brand mo
- **Video format:** hal. Vertical 9:16 para sa Reels

Tapos kopyahin ang updated na prompt.

## 4. Subukan kay Claude at i-adjust

I-paste sa Claude (o Claude Code), at sabihin ito pagkatapos ng prompt:

```text
Make this as a 1080x1920 vertical video. After the first version, show me a few still frames,
then let me tell you what to adjust (speed, colors, text) until it fits my style.
```
